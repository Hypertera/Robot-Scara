# ¡¡¡ATENCIÓN!!!

Asegúrate de tener calibrada tu impresora usando "Compensación de huecos" y "Compensación de contornos". Recomiendo revisar cada archivo para comprobar medidas y ajustar el modelo según las capacidades de tu impresora.
